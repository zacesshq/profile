# Support

## Getting help

- **Questions and ideas:** start a thread in [Discussions](https://github.com/orgs/zacesshq/discussions).
- **The tool fails or writes something wrong:** open an issue with the
  [bug report form](https://github.com/zacesshq/profile/issues/new?template=bug_report.yml).
- **Something is hard to read or a need is missing:** use the
  [accessibility form](https://github.com/zacesshq/profile/issues/new?template=accessibility.yml). An
  accessibility problem is a bug. You never need to share a diagnosis or anything personal.
- **An app you would like supported:** use the
  [new target form](https://github.com/zacesshq/profile/issues/new?template=new_target.yml).
- **Help with a profile or a target:** email [support@zacess.com](mailto:support@zacess.com).
- **Security vulnerabilities:** never open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Anything else:** email [contact@zacess.com](mailto:contact@zacess.com).

## Self-help

- [README.md](README.md) for install steps, the commands and the targets
- [spec/SPEC.md](spec/SPEC.md) for every field a profile can hold
- [ACCESSIBILITY.md](ACCESSIBILITY.md) for the measured ratios and the known limits

> [!TIP]
> `zprf check --verbose <profile>` lists every pair with its measured ratio and floor.
> Paste that output into an issue and we can see exactly what you see.
